# S5 — Steinberg Five for iPhone

Native SwiftUI version of the S5 five-day hybrid workout plan.

## Run

1. Open `S5.xcodeproj` in Xcode.
2. Choose an iPhone simulator and press Run.
3. To install on a physical iPhone, choose your Apple Developer team under **Signing & Capabilities**, connect the phone, and press Run.

## TestFlight / App Store

Set the final bundle identifier and Apple Developer team, create the app in App Store Connect, then archive and distribute from Xcode.
